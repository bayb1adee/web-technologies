ASP.NET Web Form (practice)

A slightly richer form with a TextBox, a Button and a Label.

This exercise runs on a server with ASP.NET Web Forms. The page below shows the exact .aspx markup and C# code-behind, plus a live JavaScript simulation.

Live simulation

Type your name and press Greet. On the server, cmbGreet_Click reads txtName.Text and writes the result into the label.

—

Default.aspx (markup)

<%@ Page Language="C#" AutoEventWireup="true"
    CodeBehind="Default.aspx.cs" Inherits="Project6._Default" %>

<form id="form1" runat="server">
  <asp:TextBox ID="txtName" runat="server" placeholder="Your name" />
  <br />
  <asp:Button ID="cmbGreet" runat="server"
              OnClick="cmbGreet_Click" Text="Greet" />
  <br />
  <asp:Label ID="lblResult" runat="server" Text="—" />
</form>

Default.aspx.cs (code-behind)

using System;

public partial class _Default : System.Web.UI.Page
{
    protected void Page_Load(object sender, EventArgs e)
    {
    }

    protected void cmbGreet_Click(object sender, EventArgs e)
    {
        lblResult.Text = "Hello, " + txtName.Text + "!";
    }
}
