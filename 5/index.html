OOP in C# — “Bremen Town Musicians”

Inheritance and polymorphism, modelled with the heroes of the Brothers Grimm fairy tale.

Live simulation

Normal — each hero says his own phrase (polymorphism). Strange voice — each hero is shown but the sound is produced by the next hero (the fairy-tale trick).

Press a button to let the heroes speak.

The class hierarchy

class AHero {                                   // base hero
    internal virtual string Say() { return "Hi"; }
}

class APet : AHero { }                          // group of animals

class ADog   : APet { internal override string Say() { return "Gav"; } }
class ACat   : APet { internal override string Say() { return "Miau"; } }
class AGallus: APet { internal override string Say() { return "ku-ka-re-ku"; } }
class ASinus : APet { internal override string Say() { return "i-a"; } }

class AHomo  : AHero {                          // the Troubadour
    internal override string Say() { return "I love the princess!"; }
}

Polymorphism

All heroes are stored in one array of the base type. Calling Say() invokes the correct overridden method.

AHero[] ah = { new ADog(), new ACat(), new AGallus(),
               new ASinus(), new AHomo() };

Label1.Text = "";
foreach (AHero AH in ah) {
    Label1.Text += AH.Say() + "<br>";
}

Strange voice (the fairy-tale logic)

int j = 0;
for (int i = 0; i < ah.Length; i++)
{
    j = (i < ah.Length - 1) ? i + 1 : 0;   // next hero, wraps around
    Label1.Text += "A " + ah[i].GetType().Name +
                   " says " + ah[j].Say() + "<br>";
}
