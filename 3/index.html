Arrow Functions (ES6)

Project 2 refactored so that every function is declared with the arrow syntax () =>.

Demo

Identical behaviour to Project 2, but all callbacks are now arrow functions.

Press a button to render the array.

Regular function → arrow function

// Before (Project 2)
a.forEach(function (item) {
  console.log(item);
});

// After (Project 3) — arrow function
a.forEach((item) => {
  console.log(item);
});

// Even shorter for a single expression
a.forEach(item => console.log(item));
const First = () => {
  const cards = document.querySelector("#cards");
  cards.innerHTML = "";
  a.forEach(item => cards.innerHTML += `<div>${item}</div>`);
};

const Second = () => {
  const cards = document.querySelector("#cards");
  cards.innerHTML = "";
  a.forEach((item, index) => {
    const shifted = a[(index + 1) % a.length];
    cards.innerHTML += `<div>${shifted}</div>`;
  });
};
