SPA — Single Page Application

Only the part of the page that actually changes is modified; the rest stays put.

Demo

The three views live on one page. Clicking a button hides every <div> and shows the requested one.

Code

const showPage = (page) => {
  // Hide all other pages
  document.querySelectorAll("div.page").forEach(div => {
    div.classList.remove("active");
  });
  // Show the requested page
  document.querySelector("#" + page).classList.add("active");
};

document.querySelectorAll("button[data-page]").forEach(button => {
  button.onclick = () => showPage(button.dataset.page);
});

A tiny CSS rule drives the hiding:

.page { display: none; }
.page.active { display: block; }
