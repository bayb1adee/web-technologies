Protected Folders

Restricting access to a directory with HTTP authentication.

What it is

A protected folder is a directory that asks the visitor for a username and password before serving its files. The browser shows a login dialog and sends the credentials with every request. This is how the “Confucius” sample protects its /A/ folder.

It is not the strongest defence on its own, but it is a standard first barrier — especially when combined with HTTPS.

Apache: .htaccess + .htpasswd

# .htaccess  (place inside the folder to protect)
AuthType Basic
AuthName "Restricted Area"
AuthUserFile /home/user/.htpasswd
Require valid-user
# create a password file (one user)
htpasswd -c .htpasswd matvey

ASP.NET / IIS: web.config

<configuration>
  <system.web>
    <authentication mode="Windows" />
    <authorization>
      <deny users="?" />   <!-- deny anonymous visitors -->
    </authorization>
  </system.web>
</configuration>
