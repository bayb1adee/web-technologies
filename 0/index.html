Responsive Design — the viewport

The <meta name="viewport"> tag makes the page adapt to a phone screen. Media queries change styles depending on the window width.

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Resize the browser window: the box below is light gray on a narrow screen and turns light blue when the width is at least 700px.

Resize me — I change colour (media query)
