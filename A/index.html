DropDown

Replacing a bunch of colour buttons with a single <select> dropdown.

Demo

Pick a colour from the dropdown — the #hello element changes to the selected value.

Hello!

Markup

<h1 id="hello">Hello!</h1>
<select id="color-change">
  <option value="red">Red</option>
  <option value="blue">Blue</option>
  <option value="green">Green</option>
</select>

Code

document.addEventListener("DOMContentLoaded", () => {
  document.querySelector("#color-change").onchange = () => {
    document.querySelector("#hello").style.color = this.value;
  };
});

Because an arrow function has its own this binding, the cleanest ES6 version reads the value from the element directly:

document.addEventListener("DOMContentLoaded", () => {
  const select = document.querySelector("#color-change");
  select.onchange = () => {
    document.querySelector("#hello").style.color = select.value;
  };
});
