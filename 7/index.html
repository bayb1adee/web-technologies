JS Event-Driven Programming

An app that determines the current date and time using event handlers.

Demo

The handler is attached only after the DOM is fully loaded (DOMContentLoaded).

—

Code

document.addEventListener("DOMContentLoaded", () => {
  document.querySelector("#show").onclick = () => {
    document.querySelector("#date").textContent = new Date().toLocaleString();
  };
});

A few useful Date methods:

const now = new Date();
now.toLocaleDateString();   // "11/2/2026"
now.toLocaleTimeString();   // "16:25:03"
now.getFullYear();          // 2026
now.getDay();               // day of the week (0 = Sunday)
