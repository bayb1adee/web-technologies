ASP.NET Web Form

A Web Form with a Label, a Button and C# code-behind.

This exercise runs on a server with ASP.NET Web Forms. The page below shows the exact .aspx markup and C# code-behind, plus a live JavaScript simulation so you can see the intended behaviour.

Live simulation

Clicking Start should update the label — exactly what cmbStart_Click does on the server.

Default.aspx (markup)

<%@ Page Language="C#" AutoEventWireup="true"
    CodeBehind="Default.aspx.cs" Inherits="Project4._Default" %>

<!DOCTYPE html>
<html>
<head><title>ASP.NET Web Form</title></head>
<body>
  <form id="form1" runat="server">
    <asp:Label ID="lblResult" runat="server" Text="Label" />
    <br />
    <asp:Button ID="cmbStart" runat="server"
                OnClick="cmbStart_Click" Text="Start" />
  </form>
</body>
</html>

Default.aspx.cs (code-behind)

using System;

public partial class _Default : System.Web.UI.Page
{
    protected void Page_Load(object sender, EventArgs e)
    {
    }

    protected void cmbStart_Click(object sender, EventArgs e)
    {
        lblResult.Text = "Hello from ASP.NET Web Form!";
    }
}
