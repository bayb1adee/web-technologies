Back End

The server side: logic, data and security that the user never sees.

What is Back End?

The back end runs on the server and handles business logic, data storage, authentication and communication with the client.

  • ASP.NET — Microsoft's server-side web framework (Web Forms, MVC).
  • C# — the object-oriented language used for server code.
  • Databases — SQL Server, stored data, queries.
  • Security — SSL/TLS, RSA, protected folders, configuration.
