CSS Grid Layout Module

A menu built with CSS Grid, pointing to the Front End and Back End pages.

Grid menu

The container uses display: grid with automatic columns and a gap between them.

Front EndHTML · CSS · JavaScript Back EndASP.NET · C# · databases 
.grid-menu {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
  gap: 18px;
}
