Front End

Everything the user sees and interacts with in the browser.

What is Front End?

The front end is the client side of a web application — the part that runs in the user's browser and is responsible for the interface, layout and interaction.

  • HTML — the structure of the page (headings, paragraphs, images, forms).
  • CSS — the presentation (colours, layout, typography, responsiveness).
  • JavaScript — the behaviour (events, dynamic content, interaction).

Technologies of this course

HTML

Semantic markup, DOM, forms, attributes.

CSS

Grid, Flexbox, media queries, animations.

JS

ES6, arrow functions, events, SPA, jQuery.
